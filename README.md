## Лабораторная работа №1 — «Классы»

**ФИО:** Бынеев Дмитрий

**Лабораторная работа:** №1  
**Предметная область:** Служба доставки еды

### Реализованные сущности

В рамках лабораторной работы реализована объектная модель службы доставки еды:

- `Client` — клиент службы доставки;
- `Restaurant` — ресторан;
- `DishCategory` — категория блюда;
- `Dish` — блюдо ресторана;
- `Order` — заказ клиента.

### Реализованные возможности

- создана доменная модель предметной области;
- подготовлены тестовые данные в виде коллекций в памяти;
- добавлено не менее 10 экземпляров каждого класса;
- реализованы LINQ-запросы для аналитики;
- добавлены unit-тесты с использованием xUnit v3;
- настроена автоматическая проверка тестов через GitHub Actions.

### Реализованные аналитические запросы

1. Получение пяти ресторанов с наибольшим количеством заказов.
2. Поиск заказов с минимальным временем доставки.
3. Получение клиентов, которые оформляли заказы в выбранном ресторане.
4. Получение статистики по категориям блюд за указанный период:
   - количество заказов;
   - средняя стоимость заказа;
   - общая стоимость заказов.
5. Поиск всех клиентов с максимальной суммой расходов за всё время.
