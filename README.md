### Реализованные возможности
- Проект переведён на чистую многослойную архитектуру:
  - `FoodDelivery.Domain` — доменные сущности, контекст данных и сидер;
  - `FoodDelivery.Contracts` — DTO-контракты для передачи данных и аналитики;
  - `FoodDelivery.Application` — абстракция обобщённого репозитория `IRepository<T>`, реализация `InMemoryRepository<T>` и сервисы бизнес-логики с логированием;
  - `FoodDelivery.Api` — веб-сервер ASP.NET Core Web API с REST-контроллерами;
  - `FoodDelivery.Tests` — unit-тесты на xUnit v3.
- Реализованы полные CRUD-операции для всех сущностей (`Clients`, `Restaurants`, `Categories`, `Dishes`, `Orders`).
- Реализован контроллер `AnalyticsController`, предоставляющий результаты 5 аналитических запросов из первой лабораторной работы.
- Настроена интерактивная документация API при помощи Scalar OpenAPI (`/scalar/v1`).
